# What is YOLO26?

YOLO26 is the latest unified real-time computer vision framework developed by Ultralytics.

It supports multiple computer vision tasks within a single framework, including:

- Object Detection
- Image Classification
- Instance Segmentation
- Semantic Segmentation
- Pose Estimation
- Oriented Bounding Boxes (OBB)
- Depth Estimation

The framework is designed for high accuracy, fast inference, and easy deployment across edge devices, CPUs, and GPUs. It introduces a lighter detection head, native end-to-end inference, and updated training strategies for improved performance over previous YOLO versions. 0

# YOLO26 Model Variants

YOLO26 provides five model sizes:

- YOLO26n (Nano)
- YOLO26s (Small)
- YOLO26m (Medium)
- YOLO26l (Large)
- YOLO26x (Extra Large)

Smaller models prioritize speed.

Larger models prioritize accuracy.

# Object Detection

Purpose:

Locate objects inside an image.

Output:

- Bounding Box
- Class Label
- Confidence Score

Example:

Input:

Image of tomato plants

Output:

Tomato Leaf → Early Blight
Bounding Box
Confidence = 98%

YOLO26 detection models are pretrained on the COCO dataset and support training, validation, prediction, and export. 1

---

# Image Classification

Purpose:

Predict what the entire image represents.

Unlike detection,

Classification does NOT locate the object.

It only predicts the class.

Example:

Input:

Entire leaf image

Output:

Apple Scab

Confidence = 99%

YOLO26 classification models use the "-cls" suffix (for example, yolo26n-cls.pt) and are pretrained on ImageNet. 2

# Why YOLO26 is Important

Compared to previous YOLO versions:

- Native end-to-end inference
- Lighter detection head
- Faster CPU inference
- Improved small-object detection
- Better deployment support
- Unified framework for multiple vision tasks 3

# Key Takeaways

- YOLO26 is a unified computer vision framework.
- Supports detection, classification, segmentation, pose estimation, OBB, and depth estimation.
- Detection predicts location + class.
- Classification predicts only the image class.
- Multiple model sizes allow balancing speed and accuracy.
- Suitable for real-time agricultural AI applications.
