# Why was this paper written?

Plant diseases reduce crop yield and cause major economic losses, especially in developing countries.

Traditional disease diagnosis:

- Requires agricultural experts
- Is slow
- Is expensive
- Is difficult in rural areas

Most previous AI models only **classify** disease.

However, farmers also need to know:

- **Where is the disease located?**
- **Can multiple infected regions be detected?**
- **Can detection happen in real time?**

This paper proposes using **YOLO object detection models** to detect and localize plant diseases quickly and accurately.

---

# Main Contributions

This paper:

1. Uses YOLOv3 and YOLOv4 for plant disease detection.

2. Detects and localizes infected leaf regions.

3. Compares YOLOv3 and YOLOv4 performance.

4. Evaluates speed and accuracy for real-time agricultural applications.

5. Demonstrates that YOLOv4 performs better than YOLOv3.

---

# Problem Statement

Traditional CNN classifiers answer:

> "This is Bacterial Spot."

YOLO answers:

> "This region of the image contains Bacterial Spot."

Localization is extremely useful for farmers because they can immediately identify the infected area.

# Why YOLO?

YOLO (You Only Look Once) is designed for:

- Object Detection
- Localization
- Real-time inference

Instead of first generating region proposals, YOLO predicts everything in one forward pass.

Advantages:

- Extremely fast
- High accuracy
- Can detect multiple objects
- Suitable for edge devices

---

# Models Compared

## YOLOv3

Older generation detector.

Advantages:

Disadvantages:

## YOLOv4

# Why mAP Matters

Accuracy tells us:

> Did the model classify correctly?

mAP tells us:

- Was the object found?
- Was the bounding box correct?
- Was the confidence high?

For object detection, **mAP is more important than plain accuracy.**

# Strengths of the Paper

# Limitations

- Uses only four disease classes.
- Dataset comes from PlantVillage (controlled environment).
- No field images.
- Limited crop diversity.
- Does not evaluate newer YOLO versions (YOLOv5–YOLOv11 or YOLO26).
