# Executive Summary

This paper investigates whether the PlantVillage dataset contains hidden biases that deep learning models exploit instead of learning actual disease symptoms.

The author demonstrates that models can predict disease classes using only a tiny portion of the image background (8 pixels), proving that PlantVillage contains significant dataset bias. As a result, models trained only on PlantVillage often perform extremely well on the dataset but fail when tested on real-world field images.

---

# Problem Statement

The PlantVillage dataset has become the most widely used benchmark for plant disease detection, with many studies reporting classification accuracies above 98%.

However, these models perform poorly on real-world images.

The author investigates whether this performance gap is caused by hidden dataset bias rather than poor model design.

---

# Main Contribution

- Demonstrated that PlantVillage contains significant capture bias.
- Showed that only 8 background pixels can predict disease classes with 49% accuracy.
- Proved that simply removing image backgrounds does not eliminate dataset bias.
- Recommended better dataset collection practices instead of relying solely on PlantVillage.

# Methodology

The author designed several experiments to measure dataset bias.

### Experiment 1

Instead of training on complete leaf images, only **8 pixels from the image background** were extracted.

If no bias existed, prediction accuracy should have been close to random guessing.

Instead, the model achieved **49% accuracy**, indicating strong hidden bias.

---

### Experiment 2

The author measured image blur as another hidden feature.

Models trained only on blur values still achieved performance much higher than random guessing.

This proved that capture conditions themselves leak information about the labels.

---

### Model Used

Random Forest Classifier (Scikit-learn)

The goal was **not** to achieve state-of-the-art performance but to expose hidden dataset bias.

# Key Concepts Learned

## Background Bias

The model learns background information instead of disease symptoms.

Example

If healthy leaves are always photographed against one background and diseased leaves against another, the model may classify the background rather than the disease.

---

## Capture Bias

Differences caused by

- Camera
- Lighting
- Blur
- Image acquisition process
- Photographer preferences

The model can learn these hidden patterns instead of learning disease characteristics.

---

## Poor Generalization

A model achieving 99% accuracy on PlantVillage may perform very poorly on real farm images.

High benchmark accuracy does not guarantee practical usefulness.

---

# Engineering Lessons

1. Never trust accuracy alone.
2. Always evaluate on unseen field images.
3. Dataset quality is more important than model complexity.
4. Background removal alone is insufficient.
5. Capture conditions must be diversified.
6. Randomize lighting and camera settings.
7. Collect images from multiple environments.
8. Validate on real-world data before deployment.
